# State flags

Small WebP copies of the public-domain state flag artwork from
[Invoxio/us-state-flags](https://github.com/Invoxio/us-state-flags), revision
`345d25694fea510893335ce65ec5343ab35dee88`, under `flags/us/<code>/<code>.svg`.
The collection credits Wikimedia Commons public-domain originals.

Includes all 50 states and the District of Columbia so the top-state ranking
can change without losing flags. Images preserve their source proportions,
fit within 96 × 64 pixels, and are served locally.
