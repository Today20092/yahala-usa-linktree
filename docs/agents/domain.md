# Domain docs

This is a single-context repository for the Ya Hala landing page and link hub.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If either location is absent, proceed silently. Create domain documentation only when terminology or an architectural decision is actually resolved.

## Vocabulary

Use the repository's domain terms consistently in specifications, tickets, tests, and implementation. Prefer the names in `CONTEXT.md` and the site data model over new synonyms.

## Architectural decisions

Surface any conflict with an existing ADR explicitly rather than silently overriding it.
