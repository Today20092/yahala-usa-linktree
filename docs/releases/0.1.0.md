# 0.1.0 — Homepage refinement

October 25, 2026.

## Changes

- Add direct Instagram sponsorship/contact actions near the introduction and after the portfolio.
- Label the existing audience figures as combined video views; preserve source figures and dates.
- Show the host clearly in the desktop hero crop.
- Bring the latest story before statistics and brands on phones; preserve the desktop visual order.
- Enlarge secondary navigation targets and shorten the tablet cover.
- Initialize video search independently of visibility while retaining its service-readiness guard.
- Use a native QR modal for keyboard focus containment and predictable dismissal.
- Add independent pause/resume controls to brand and story motion, including focus/hover pause for stories.
- Preserve the owner's preferred compact horizontal story rows, including reduced-motion presentation.

No route, configuration-input, stored-data, or Worker API migration is required. This release retains the current development/main deployment workflow and updated dependencies.

## Validation

The original refinement passed desktop and phone browser checks for QR focus/dismissal, pause/resume, navigation, story filters, sorting, pagination, back navigation, and empty-state recovery. Isolated API fixtures covered search loading, empty, Arabic results with timestamp links, errors, and retry. Release integration runs the current CI checks and built-asset smoke boundary before promotion.

## Known limitations

Physical iOS/Android devices and native screen-reader speech have not been tested. Reduced-motion story rows intentionally retain the compact clipped presentation requested by the owner; the Story Browser remains the full catalog path. Production search availability depends on the existing Worker bindings and indexed transcripts. Use a previous Worker version to roll back code/assets; no stored-data rollback is required by these changes.
