# Ya Hala 0.3.1

Restores the collaboration-logo integration for all 18 existing brands. Every
brand points to a local asset, including the newly published Zyara logo, so
production's image policy permits the images without allowing external hosts.
MOKAFÉ uses the user-confirmed name; Yaffa and Zyara match their saved video
addresses and official websites. The separate research shortlist is unchanged.

Data validation now rejects missing/external collaboration logos. The rendered
browser regression checks every brand's image loads and decodes under a
self-only image policy, with phone/desktop layouts and both system color
preferences. Production retains its existing fixed light theme.

No stored service data changes. Reverting the commit or Worker deployment
restores the prior version. Physical-device and screen-reader checks remain
manual; passing automation does not establish full WCAG conformance.
